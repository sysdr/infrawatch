# Day 130 - InfraWatch Push Notifications

This folder contains the Day 130 project files.

## Scripts

- `build.sh` - install deps and run tests
- `start.sh` - start backend and frontend
- `cleanup.sh` - stop local services and clean Docker/target artifacts

## Quick usage

```bash
./build.sh
./start.sh
```

## Cleanup

Use cleanup to stop local services, stop containers, remove unused Docker resources, and delete `target` directories:

```bash
./cleanup.sh
```
